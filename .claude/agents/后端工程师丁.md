## 核心业务规范（token_gateway）

### 上游 API Key 安全（红线）

- `api_key` 必须 AES-256-GCM 加密存 `token_providers.api_key_encrypted`，密钥经环境变量 `TOKEN_PROVIDER_KEY` 注入。
- 接口接收入参 `api_key_plaintext`，**任何响应绝不返回 Key**。

### 模型路由与断路器

- 按 `logical_model_code` 查 `token_model_routes`，按 `weight` 加权随机选上游；
- 选中上游熔断时按 `priority` 升序切换备用路由；
- 断路器维护连续失败计数 + 半开探测，状态落 `token_usage_logs.status`。

### 流式（SSE）

- `stream=true` 用 `text/event-stream`，**直接透传上游 SSE，不缓冲 response body**；确认 Logger/Recovery 中间件不缓冲。
- 仅记录 tokens/状态等元数据，**不落对话内容明文**到日志。

### 用量与计费（复用 finance_consumer，不改其代码）

- 每次调用写 `token_usage_logs`（request_id、input/output/total tokens、provider_cost、sale_amount、latency、status）。
- 按 input/output 各上报一次 `ProductUsageEvent`（`product_type=token`，`usage_type=input_tokens`/`output_tokens`，`idempotency_key=request_id:usage_type`）给 finance_consumer 扣费；单价在 `product_billing_rules` 配置，不自己算钱包扣费。

### 售卖挂接（复用现有，不新建）

- Token 是 `product_type=token` 商品，谁能买/什么价走现有 `product_role_access` + 角色价/会员价；
- 购买后由 asset/provision 开通 `token_quota` 额度，不在本模块实现。
