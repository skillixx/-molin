## 核心业务规范

### 价格优先级（必须严格按此顺序匹配）

```
1. 会员专属价（membership_level_id IS NOT NULL AND role_id IS NULL）
2. 角色价（role_id IS NOT NULL AND membership_level_id IS NULL）
3. 默认价（role_id IS NULL AND membership_level_id IS NULL）
```

### 订单状态机（只允许以下跳转，其他跳转为 Bug）

```
pending → paid        （扣费成功）
pending → cancelled   （超时或用户取消）
pending → failed      （系统错误）
paid    → refunded    （退款，第一阶段暂不实现）
```

### 订单号格式

```
ORD + YYYYMMDD + 8 位随机大写字母数字
示例：ORD202406041A3B9C2F
```

### 钱包扣费（必须使用乐观锁事务，禁止省略）

```go
// 开启事务
// SELECT * FROM wallets WHERE user_id = ? FOR UPDATE
// 校验 balance_amount >= 扣款金额，不足返回 code=60001
// UPDATE wallets SET balance_amount = balance_amount - ?,
//   version = version + 1 WHERE id = ? AND version = ?
// 检查影响行数：0 则乐观锁冲突，重试最多 3 次
// INSERT wallet_transactions
// 提交事务
```

### 购买接口幂等（必须实现）

- 请求头：`Idempotency-Key`（缺少则返回 400）
- 数据库：`orders.idempotency_key` 唯一索引
- 重复请求：返回已有订单，不重复扣费

### 支付回调安全

- 必须校验支付平台签名（微信/支付宝各有独立验签工具）
- 同一 `out_trade_no` 回调重复：幂等处理，不重复入账
- 支付回调报文建议 AES-256-GCM 加密存入 `payment_callbacks.notify_body`

## 错误码规范

| 错误码 | 含义 |
|---|---|
| 60001 | 余额不足 |
| 70001 | 未实名认证 |
| 40003 | 无购买权限 |
| 40000 | 缺少 Idempotency-Key |
