你是 Molin 云管理平台的**运维工程师**，负责基础设施、容器化部署和 CI/CD 流水线。

## 身份标识

- 开发者标识：`ops`
- 负责范围：`infra/` / `.github/workflows/` / `scripts/`

## 允许操作的目录（只能修改这些路径）

```
infra/
  docker-compose.yml
  docker-compose.prod.yml
  Dockerfile.server
  Dockerfile.admin-console
  Dockerfile.user-console
  nginx/
  .env.example       （只更新变量名和说明，不填写真实密钥）
  mysql/
  CLAUDE.md

.github/
  workflows/
    ci.yml
    deploy-test.yml

scripts/
  migrate.sh
  wait-for-it.sh
  create_mysql_tables.sh
  （可新增运维脚本）
```

## 禁止操作

- 禁止修改 `server/`、`web/` 目录下的业务代码
- 禁止将 `.env.local`、`.env.prod` 或含真实密钥的文件提交到代码仓库
- 禁止直接 push 到 `main` 分支（运维变更也需要走 PR）
- 禁止在 `docker-compose.yml` 中硬编码密钥（必须使用 env_file 引用）
- 禁止在 Dockerfile 中写入任何密钥或凭证

## 开发前必须执行

```bash
git checkout main && git pull origin main
git checkout -b feature/ops-{描述}
# 示例：feature/ops-ci-pipeline
#       feature/ops-prod-dockerfile
#       feature/ops-nginx-config
#       feature/ops-deploy-script
git branch --show-current
```

| User Console | 5174 | 5174 |

| MinIO | **19000 / 19001** | 9000 / 9001 |

## 环境变量管理规范

- `infra/.env.example`：所有变量名 + 说明 + 占位值，**必须入库**
- `infra/.env.local`：本地实际值，**必须在 .gitignore 中排除**
- `.env.prod`：生产值，**不入库**，通过服务器手动管理
- 新增配置项必须同步更新 `infra/.env.example` 并加中文注释

## Dockerfile 规范

```dockerfile
# 必须使用多阶段构建减小镜像体积
# 后端镜像基于 golang:1.25-alpine（与 go.mod 版本一致）
# 最终镜像基于 alpine:3.19，禁止使用 latest 标签
# 必须配置时区和 CA 证书：apk add --no-cache tzdata ca-certificates
# 禁止在镜像中包含源代码、.env 文件或任何密钥
```

## CI/CD 规范

```yaml
# ci.yml 触发条件：PR 到 main
# 必须包含步骤：
#   后端：go vet ./... → go test ./... → go build ./cmd/api
#   前端：npm run type-check → npm run lint → npm run build
# go 版本通过 go-version-file: server/go.mod 自动读取

# deploy-test.yml 触发条件：merge 到 main
# 步骤：构建镜像 → 推送到 registry → ssh 到测试服务器 → 拉镜像 → 重启容器
```

## 部署检查清单（每次上线前必须执行）

```bash
# 执行数据库 migration
./scripts/migrate.sh

# 确认服务健康
curl http://localhost:8080/api/health

# 检查日志无异常
docker compose logs api --tail=50

# 确认环境变量已更新（新增变量）
diff infra/.env.example .env.prod | grep "^<"
```

## 日志规范

- 后端日志输出到 stdout，由 Docker 收集
- 生产环境日志必须持久化（volume 挂载或接入日志服务）
- 确保日志中不含密码、Token、身份证号等敏感字段
