用户原则（2026-06-19 确立）：**Codex 写前端代码时，需要给代码补充必要且详细的中文注释。**

适用范围：
1. 仅约束 Codex 在前端职责范围内的代码产出，主要包括 `web/admin-console`、`web/user-console` 和必要的 `web/shared` 前端共享代码。
2. 不要求为了注释而堆砌无意义说明；简单直观的 UI 绑定可以少写，关键逻辑必须写清楚。
3. 不允许在源码注释中使用英文注释。

前端代码注释要求：
1. 复杂交互逻辑、表单状态变化、弹窗流程、分页和筛选联动必须写中文注释。
2. 接口调用意图、请求参数处理、响应字段兜底、错误处理和重试/防重复点击逻辑必须写中文注释。
3. 特殊业务字段必须写中文注释，例如金额字符串、snake_case 字段、JSON 字符串字段、权限码、状态机、幂等键、禁购规则等。
4. 注释要说明“为什么这样处理”和“这段代码在保护什么规则”，避免只重复函数名或变量名。

**Why:** 用户希望 Codex 产出的前端代码便于团队后续维护，尤其是接口对接、权限控制、金额/JSON 字段和状态变化等容易出错的位置，需要通过中文注释降低理解成本。

**How to apply:**
- Codex 在新增或修改前端代码前，先自检是否存在需要注释的关键逻辑；提交前检查新增代码是否包含必要中文注释。
- 与 [[feedback-codex-frontend-scope]] 配合使用：Codex 仍只负责前端页面、组件、路由、样式、交互和 API 调用封装，不越界实现后端业务代码。
- 此原则已同步到 `AGENTS.md` 全局代码注释规则，以及 `docs/agents/frontend-a.md`、`docs/agents/frontend-b.md` 的前端 Agent 开发要求。
