## 6. 计价和舍入规则

- 内部价格、用量和小计使用 `DECIMAL(24,12)` 或 `shopspring/decimal`。
- 钱包、冻结金额和流水保持现有 `DECIMAL(18,6)`。
- 按每个 Usage Item 计算高精度小计，在逻辑请求总额处只舍入一次。
- 最终人民币金额使用四舍五入保留6位小数。
- 成功且存在正用量的请求，舍入后最低收费为 `0.000001 CNY`。
- 不启用显式上下文缓存销售项；供应商缓存优惠只记入成本对账，不改变本版本用户输入售价。
- 免费额度不抵扣客户账单，也不计入毛利计算。

## 7. 预占与失败收费

```text
预占金额
  = 已知输入 Token × 输入售价
  + max_output_tokens × 输出售价
  + 已启用的其他最坏计费项
```

- 鉴权、模型权限、内容安全、预算、并发或余额检查失败：不调用上游，不收费。
- 上游明确拒绝且未产生有效模型输出：释放全部预占，不收费。
- 返回有效输出和可信 Usage：按价格快照结算，多退。
- 返回输出但 Usage 缺失：进入 `pending_reconcile`，禁止直接按 `max_tokens` 结算。
- 执行结果未知：保留可审计状态并进入人工或自动对账，不自动切换供应商。
- 同一 `request_id` 只能进入一个终态结算路径。

## 8. 发布门槛

本冻结表允许工程开发，不等于模型已经公开上架。每个模型发布前必须分别满足：

1. 当前账号具备模型调用权限和充足余额。
2. 普通响应、SSE、Usage、思考 Token、错误和断连契约测试通过。
3. 主备端点均存在时，完成参数和计量等价性测试。
4. 官方成本复核未上涨；若上涨，创建新价格版本。
5. 产品、财务和合规批准销售价、内容策略和用户文案。
6. 模型默认状态为 `draft`；禁止通过 Migration 直接公开发布。
