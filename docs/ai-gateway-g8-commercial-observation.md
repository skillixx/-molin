# AI 网关 G8 商业观察

> 当前状态：尚未开始。真实客户、真实资金、生产目标、价格、告警联系人和付费预算均需独立授权与批准。

## 1. 四周目标

| 指标 | 门禁 |
|---|---|
| 设计客户 | 至少 3 家确认 |
| 真实 API 集成 | 至少 2 家，不以控制台演示替代 |
| 真实付费 | 至少 1 家使用自有资金并连续使用 4 周 |
| 请求成功率 | 四周不低于 99.5% |
| 正常账单差额 | 持续严格为 0 |
| 毛利 | 单客户、单模型不低于批准值；默认 15% |
| 财务安全 | 无重复扣费、负余额、未释放预占或不可追踪结算 |
| 缺陷 | P0=0、P1=0 |

## 2. 每级灰度

```text
内部合成请求
  -> 单个设计客户
  -> 少量设计客户
  -> 已批准范围
```

每级重新核对成功率、P50/P95/P99、TTFT、429/5xx/超时/断连、Usage、三项账务差额、hold、Outbox、补偿、内容审核、并发租约、毛利、告警和客户反馈。不得自动扩大范围。

## 3. 周报最小字段

- 周期、精确制品、客户数量、真实集成数量、请求量和成功率。
- P50/P95/P99、TTFT、错误分布、Bifrost 节点与告警触发/恢复。
- 正常账单三项差额、异常数量/SLA/审计入口、未释放 hold、Outbox/补偿。
- 单客户/单模型收入、成本、毛利率和批准底线。
- 客户反馈、事件、回滚、凭据轮换/吊销/回收状态。

赠送余额、Mock、沙箱调用和供应商控制台测试不得计入真实付费证据。
