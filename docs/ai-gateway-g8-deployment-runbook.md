# AI 网关 G8 上线与灰度手册

> 本手册默认只用于隔离生产形态预演。连接生产、部署生产、运行真实付费请求、开放客户或配置真实通知前，必须获得绑定 ChangeId 的独立精确授权。

## 1. 变更单

必须记录：ChangeId、精确目标、源码提交、制品 SHA-256/digest、配置摘要、责任人、维护窗口、最大请求数、最大费用、客户范围、回滚点和停止条件。不得在聊天、文档或命令行参数中粘贴明文密钥。

## 2. 只读预检

1. 核对主机、进程、活动请求、环境文件权限、schema、表规模、备份、Redis、RabbitMQ、Bifrost、Prometheus、Alertmanager、Grafana 和日志。
2. 保存旧 API/前端/监控配置摘要与制品，不复制环境文件正文。
3. 运行 `docker compose config --quiet`、Promtool、Nginx 配置检查和只读账务对账。
4. 确认 `AI_GATEWAY_TRAFFIC_ENABLED=false`，客户入口关闭。

## 3. 关闭态部署

1. 部署固定摘要制品，不使用 `latest`，不执行未批准 Migration。
2. 验证 health/ready、TLS、SSE buffering、请求体限制、超时、连接数、日志轮转和内部指标强鉴权。
3. 验证 22 条规则、16 面板、P0/P1 路由配置和 discard 默认接收器；未经批准不得发送真实通知。
4. 运行只读对账，要求三项差额和全部异常/积压为 0。

## 4. 授权后的灰度

1. 内部合成请求使用唯一幂等键，严格限定请求数和费用；失败或结果未知不得盲重试。
2. 对账为 0、监控正常且回滚可用后，才对单个设计客户开启。
3. 每级扩大前重新核对 SLO、账务、毛利、安全、告警和反馈。
4. 任何停止条件触发，立即关闭总闸并执行回滚手册。

## 5. 证据

保存脱敏命令摘要、开始/结束时间、制品摘要、配置摘要、请求数、费用、成功率、P95/P99、账务报告、告警状态、客户数量、毛利和凭据回收状态。上游 2xx 只能写“上游受理”，不能替代客户收到或账务完成证据。
