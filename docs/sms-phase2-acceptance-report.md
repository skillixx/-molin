# 阿里云短信验证码阶段 2 测试与验收报告

## 当前结论

阶段 2 的代码、迁移、接口契约、本地自动化、远程 CI、隔离测试部署和受控真实短信验证已经完成。测试服部署提交为 `34b69a4`，数据库为 `59:0`；PR #315 当前提交对应的 [GitHub Actions 运行 #375](https://github.com/skillixx/-molin/actions/runs/30820296650) 已通过后端 MySQL 8/Redis 7/Linux race、管理后台构建和用户控制台构建。

真实窗口完成了模板同步、五场景绑定、一次管理测试发送以及五业务入口发送。共 7 条阿里云受理记录，其中一条是第一次换绑流程因本地停止超时留下的额外 `bind_phone` 受理记录。用户确认最后四条收件为“原白名单手机号 3 条、新绑定管理员手机号 1 条”；此前换绑与管理员验证短信的验证码均成功消费。窗口结束后安全状态与原白名单均已恢复，运行时敏感扫描通过。

真实验证同时暴露出阶段 0 外部准备证据与运行状态不一致：真实同步只有 1 个合格模板，五场景全部绑定它，违反“五场景分别使用独立模板”的硬性产品规则。独立测试工程师和产品经理均判定不通过；当前结论为“技术开发与短信可达性验证完成，但阶段 2 验收失败”，PR #315 不得合并，也不得进入阶段 3。
