# AI 网关 G6 用户端模型市场与完整客户旅程功能说明

> 状态：代码实现与本地自动化测试进行中；测试环境、真实 Bifrost、独立验收和 PR 结论见 `ai-gateway-g6-acceptance.md`。

## 1. 使用角色与入口

G6 面向已登录的小型企业客户，把“找模型、看人民币价格、获得平台 SK、调用文字模型、核对费用”收口到用户控制台的 AI 服务导航。

| 页面 | 功能 |
|---|---|
| `/ai/models` | 搜索、筛选和比较已发布文字模型 |
| `/ai/models/:modelCode` | 查看发布资料、人民币销售价、文档和接入参数 |
| `/ai/api-keys` | 管理本人 Project 与平台 SK |
| `/ai/usage` | 查看本人用量总览、请求账本、计价、钱包流水、导出和申诉 |

旧 `/api-keys` 与 `/token/usage` 自动重定向到新入口；通用商品消费记录仍使用 `/consumption`，不与 AI 请求事实混为一套。

## 2. 模型与文档规则

1. 只展示发布快照中模态为 `chat`、当前有人民币价格且存在健康执行路由的模型。
2. 用户可按名称、公开代码、厂商、能力和上下文筛选，并按最新、价格、上下文或名称排序。
3. 详情展示输入、输出、缓存、推理 Token 销售价、最低收费、舍入、失败收费和生效时间，不展示成本或内部路由。
4. 模型介绍、快速入门和 API 文档只保存外部 HTTP/HTTPS URL。健康状态不是 `healthy` 时按钮禁用并说明原因。
5. Quick Start 展示公开 Base URL、公开模型代码和服务端环境变量写法；完整代码示例只在后台审核发布的静态网页维护。

## 3. Project 与平台 SK 规则

- Project 是模型权限、预算、并发和消费归集边界，用户只能管理本人数据。
- 支持创建、编辑名称/时区和归档；展示月预算及最终生效的并发、RPM、TPM。
- 平台 SK 默认模型 allowlist，支持签发、轮换和吊销；签发/轮换后的完整值只展示一次，后续只显示名称、前缀、状态和最近使用时间。
- 未实名用户不能签发或轮换可调用 SK。轮换、吊销和归档均有二次确认与反馈。
- 完整 SK 不进入 URL、日志、文档、请求账本或浏览器持久化存储。

## 4. 用量与账单规则

- 总览展示今日、本月请求量、输入/输出 Token、人民币已结算金额和预算进度。
- 账本按 Project、SK、模型、执行/结算/安全状态和时间筛选，仅返回本人记录。
- 详情展示 request_id、三维状态、上游确认用量、价格版本、销售计价行、结算金额及钱包预占/结算/释放流水。
- 不展示提示词、模型正文、内部执行模型、上游请求头或完整 SK。
- CSV 必须选择不超过 93 天的范围，最多 5000 行，并防止公式注入。
- 用户按 request_id 提交 10 至 1000 字账单申诉；同一用户对同一请求只保留一条可追踪事实。

## 5. 非本期范围

- 图片、视频、音频执行、异步任务和对象存储生命周期。
- 生产部署、生产密钥和真实客户流量。
- 在墨灵数据库中保存或编辑静态文档正文。
