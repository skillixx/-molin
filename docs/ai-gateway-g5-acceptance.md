## 必测场景

1. 缺少价格、健康启用渠道、文档或快速入门时模型发布失败；配置完整后生成连续快照。
2. 同一模型并发发布、同一路由并发更新只能有一个成功，另一方返回 409。
3. 价格四项计量缺失、毛利不足、成本过期、时间窗重叠均拒绝发布。
4. `provider_model` 不含明确 provider 时拒绝；`route:{id}` 运行时发送后台发布值，旧模型继续使用冻结映射。
5. 审计服务失败时模型、渠道、价格和路由写操作不落库。
6. JSON 顶层或嵌套重复键、未知字段、尾随文档均返回 400。
7. 只有确认未发送时允许有限重试；超时、流中断、HTTP 响应或结果未知不重试。安全失败达到阈值后，下一请求避开熔断路由；失败请求不生成用量事实，账务消费者继续按请求事实幂等结算。
8. 375px、768px、1440px 下无按钮失效、文本遮挡或表单溢出。
