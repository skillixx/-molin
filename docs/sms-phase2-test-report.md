## 未执行和残余门禁

1. 本机没有 Docker、MySQL 客户端和可用的隔离 MySQL 8；`SMS_MIGRATION_TEST_DSN` 未配置，因此迁移测试按显式门禁安全跳过，尚未执行真实 MySQL 8 的 `1→59→58→59` 隔离矩阵。
2. `SMS_ENABLED` 保持关闭，未使用真实密钥、未调用阿里云 SendSms、未产生短信费用。
3. Redis Lua 的键、原子计数、TTL、重试秒数与失败关闭已通过测试替身单测；真实 Redis 7 原子计数、限流和 TTL 用例已纳入 CI，但远程流水线尚未执行，恢复周期仍需 QA 观察。
4. 尚未由独立测试工程师复核，也未由产品经理正式批准。
5. 尚未推送分支、创建 PR、运行远程 CI 或合并。
6. 当前 Windows Go 环境未启用 CGO，`go test -race` 无法执行；并发正确性已由数据库唯一约束、乐观锁及单元测试覆盖，race 仍应交由 Linux CI 补跑。

真实验证需单独授权，并限定白名单号码、单次窗口、费用上限和回滚动作；阿里云返回 `OK/accepted` 后仍需人工确认实际收件。
