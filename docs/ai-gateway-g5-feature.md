# AI 网关 G5 管理工作台功能说明

> 状态：PR #321 已合并，测试环境 Migration `000064`、真实 Bifrost/Bailian 联调和 QA/产品双签均已通过。G5 允许进入 G6；本结论不包含生产部署和多模态执行链路。

## 功能与角色

G5 面向墨灵运营管理员，把此前依赖 SQL、命令行和分散接口的配置收口为“Token 网关 → AI 网关工作台”。所有入口必须登录、具备对应细粒度权限并完成管理员双重认证。

| 区域 | 作用 | 写权限 |
|---|---|---|
| 运行概览 | 请求量、成功率、Token、销售额、成本、毛利、治理拒绝和配置异常 | `ai_gateway:view` |
| 模型发布 | 文字、图片、音频、视频模型资料，发布、下架和不可变版本 | `ai_gateway:model_manage` |
| 价格版本 | 人民币成本价和销售价，草稿、审批、发布、暂停、退役 | `ai_gateway:price_manage` |
| Bifrost 路由 | `provider/model`、优先级、权重、超时、重试、熔断和回退顺序 | `ai_gateway:route_manage` |
| 内容安全 | G4 安全策略、事件、处置和申诉 | `ai_gateway:safety_manage` |
| 并发与配额 | 用户、Project、SK、模型维度的并发/RPM/TPM | `ai_gateway:resource_manage` |
| 预算与异常 | 预算、临时增额、告警、补偿和人工对账 | `ai_gateway:budget_manage` / `ai_gateway:reconcile_manage` |

## 核心规则

1. 模型资料支持供应商、介绍、能力、上下文窗口、介绍网页、操作文档和快速入门网页。文档使用 HTTP/HTTPS 静态网页 URL，无需上传 Markdown。
2. 模型发布前必须具备操作文档、快速入门、唯一生效价格，以及至少一条指向健康启用渠道的生效 Bifrost 路由。每次发布创建不可变快照，历史版本不删除；回滚会基于历史快照创建新的发布版本。
3. 价格只使用 `decimal` 和人民币，固定包含输入、输出、缓存、推理四项 Token 计量。已发布价格不可原地修改；回滚只复制为新草稿，必须重新审批和发布。
4. 图片、音频、视频的目录和展示已预留，但本阶段不开放其实际计量执行；后续增加 metric 和异步任务后才能对客户开放。
5. Bifrost 运行时只选择健康渠道上的已发布路由并使用其 `provider/model`；只有从未配置 G5 路由的旧模型继续使用冻结静态映射，已配置路由全部不可用时失败关闭。只在传输层确认请求未发送时按路由上限重试；超时、结果未知或已收到响应不得重试。安全重试耗尽后写共享熔断状态，后续请求按回退顺序选择其他可用路由。
6. 渠道 SK 只入不出，响应、审计和 UI 均不得显示明文或密文。
7. 渠道健康检测只访问 Bifrost 根路径 `/health`，不带上游密钥、不调用模型、不产生模型费用。
8. 概览销售额取已结算请求，成本使用请求保存的不可变价格快照反算；金额用十进制字符串返回，不使用浮点数。
9. 内容、预算、并发、RPM、TPM 拒绝写入脱敏事件，只保存请求标识、模型、原因和作用域，不保存提示词或生成内容。
10. 所有管理写操作先写审计；路由、资源和预算更新使用版本号防止并发覆盖。

## 页面交互

- 刷新、新建、编辑、发布、暂停、退役、下架和详情按钮都有真实交互、加载状态和反馈，写按钮按模型、价格、路由、安全、资源、预算和对账权限分别显示。
- 价格与路由使用对话框编辑，版本详情使用抽屉展示。
- 治理区域可查看拒绝事件、访问限制、用户申诉、预算告警和补偿任务，并支持限制/解除、申诉处理、临时额度和指定 Outbox 死信重试。
- 桌面端采用可扫描表格；窄屏时指标、表单和工具栏自动折行。
- 操作文档在新窗口打开静态网页，不在后台内执行第三方脚本。

## 非本期范围

- 图片、音频、视频真实生成接口、异步任务和对象存储生命周期。
- Bifrost 多节点自动发现或配置下发。
- 生产流量、生产 Migration 和生产密钥。
