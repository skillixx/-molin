# 阿里云短信验证码阶段 2 功能说明

## 功能目标

阶段 2 为墨灵平台提供短信模板管理后端能力：管理员可以只读同步阿里云模板、查看模板详情、为五个验证码场景绑定模板、控制本地启停、向白名单号码执行受控测试提交，并查询脱敏发送记录。

本阶段不包含管理后台 Vue 页面、营销/通知/群发短信、国际短信、多供应商路由、自动降级或生产放量。

## 使用角色与权限

全部接口都要求管理员登录及手机、邮箱双重认证，并按最小权限拆分：

| 权限 | 能力 |
|---|---|
| `sms:template:view` | 查看概览、模板、五场景和发送记录 |
| `sms:template:manage` | 模板本地启停和场景绑定 |
| `sms:template:sync` | 从阿里云只读同步模板 |
| `sms:template:test` | 向测试白名单提交短信 |

## 页面与接口入口

阶段 2 只交付后端接口，阶段 3 才开发管理页面。接口前缀为 `/api/admin/sms`，共九个接口：概览、模板列表、模板详情、模板同步、场景列表、场景更新、模板启停、测试发送和发送记录。

## 核心规则

1. `sms_templates` 是模板快照唯一权威来源，模板编码不进入环境变量。
2. `sms_scene_bindings` 是 `register/login/reset_password/bind_phone/admin_verify` 五场景唯一权威来源。
3. 同步只调用阿里云模板列表和新版详情读取接口，禁止创建、修改或删除云端模板和签名。
4. 只有固定签名、验证码类型、包含 `${code}` 且审核通过的模板可以启用、绑定和发送。
5. 模板启停和场景绑定都使用版本号并发保护；审核失效会安全停用模板及关联启用绑定。
6. 测试发送必须同时通过细分权限、管理员双重认证、总开关、测试模式、白名单、双维限流和幂等抢占。
7. 同一管理员相同 `Idempotency-Key` 和相同参数重放首次结果，不重复限流或外呼；修改模板、场景或号码返回冲突；不同管理员互相隔离。
8. `accepted` 仅表示阿里云受理，不表示运营商送达或用户收到。
9. 响应、发送日志和审计不包含 AccessKey、验证码、完整手机号、幂等键明文或供应商原始正文。

## 与现有业务的关系

手机注册、手机验证码登录、找回密码、换绑手机和管理员手机二次验证继续使用原接口，由统一 Dispatcher 读取当前启用的数据库绑定。供应商未受理时验证码收敛为 `failed`，不能校验。邮件注册、登录、找回密码、换绑邮箱和管理员邮箱验证继续使用独立 DirectMail 链路。

## 结果边界

本地单元/Mock、MySQL CI 和供应商真实验证是不同证据等级。未经授权时 `SMS_ENABLED` 必须保持 `false`；Mock、迁移静态检查和阿里云 `Code=OK` 都不能代替手机实际收件证据。
