# 墨灵 AI 网关上游测试账号需求与配置登记表

> 用途：由项目负责人准备和登记 AI 网关测试上游，供开发、测试、计费对账和上线评审使用。
>
> 适用范围：Phase 1 文字模型网关；后续图片、音频和视频上游可继续复制本模板。
>
> 安全要求：本文件禁止填写 API Key、AccessKey、密码、验证码、银行卡信息、完整手机号及其他密钥明文。

## 1. 填写说明

1. 每个上游单独填写一份“上游账号登记表”和一组“模型登记表”。
2. API Key 只能由项目负责人写入测试 Linux 的受限环境变量或密钥管理服务。
3. 文档中只填写环境变量名称、密钥引用名称和“已配置/未配置”，不得填写密钥值。
4. 首批至少准备两个真实上游和一个墨灵 Fake Provider。
5. 推荐组合：阿里云百炼作为国内真实上游，OpenRouter 作为 Bifrost 内置链路上游；硅基流动作为可选国内备用上游。
6. 测试账号必须与生产账号、个人账号和其他项目账号隔离。
