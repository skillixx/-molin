# 阿里云短信验证码阶段 3 功能说明

## 功能说明

阶段 3 为墨灵管理后台提供短信模板管理页面。管理员可以查看阿里云模板同步快照和统计、筛选模板、查看详情、维护五个固定业务场景的独立模板绑定、启停本地模板、执行只读同步、在安全门禁下发起白名单测试提交，并查询脱敏发送日志。

本阶段只消费阶段 2 已合并的九个管理 API，不修改阿里云云端模板、签名或白名单，不修改后端和数据库，不执行 migration，也不授权真实短信发送。

## 使用角色和权限

- `sms:template:view`：进入页面并查看概览、模板、详情、场景和发送日志。
- `sms:template:manage`：模板本地启停和五场景绑定。
- `sms:template:sync`：从阿里云只读同步模板快照。
- `sms:template:test`：在后端 MFA、开关、测试模式和白名单门禁下发起测试提交。

所有接口还要求管理员手机和邮箱双重认证有效。权限不足时页面按能力降级，不在前端伪造授权。

## 核心业务规则

1. 五个固定场景为注册、登录、找回密码、换绑手机和管理员验证，不允许新增或改名。
2. 可绑定模板必须审核通过、类型为验证码、变量精确为 `code` 且本地启用。
3. 五个启用场景必须使用不同模板；场景更新使用 `version` 乐观锁。
4. 同步只读，不创建、修改或删除阿里云模板和签名。
5. 模板停用和场景换绑均需要二次确认；冲突后刷新最新版本并保留尚未提交成功的场景表单。
6. 测试提交需要独立权限、双重认证、后端安全开关、测试白名单和幂等键。页面不模拟成功。
7. `accepted` 只显示为“供应商已受理”，不能解释为运营商已送达。
8. 完整手机号只在测试弹窗内存中短暂存在；页面、URL、日志和浏览器持久层不保存手机号、验证码或密钥。

## 页面入口

管理后台 → 消息中心 → 短信模板，路由 `/message/sms-templates`。

页面包含：概览卡片、模板列表与详情抽屉、场景绑定卡片、测试提交弹窗、发送日志、移动端筛选抽屉和权限状态提示。

## 接口清单

页面消费 `/api/admin/sms` 下的概览、模板列表、模板详情、同步、场景列表、场景更新、模板启停、测试提交和发送日志九个接口。正式字段和错误码以 `docs/full-api-design.md` 的阶段 2 管理 API 契约为准。
