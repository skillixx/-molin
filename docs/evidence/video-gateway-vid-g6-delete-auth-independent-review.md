## 后续跨期窗口仍需闭合

QA指出新增AuthorizeTx本身仍可能在查询等待期间跨过Key、权益、会员或临时allow期限，单纯重复查询不是完整解决。69880实际复现Key查询返回时跨期：根与子各发生一次不应发生的Delete。

QA确认优先沿原鉴权方法返回实际授权路径截止时间，不另写平行权限规则。必要条件按最早时限组合；同类完整候选按最晚时限组合；每个候选先与自身父资产组合，不能交叉拼接。无授权和永久授权不能都仅用nil表达。最终JWT复验后再取新时钟，并收紧Delete context。当前实现按此方案推进，65322专项与65680完整回归运行中；尚未签P1关闭。

IAM沿仓库现有精确权限码语义，不新增`video:*`通配授权。仅期限接口允许发现永久角色作为临时allow之外的有效路径；deny仍优先。
