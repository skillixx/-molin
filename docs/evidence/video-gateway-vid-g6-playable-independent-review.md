# VID-G6 可播放媒体增量独立复核

仅为增量审查，不是完整阶段验收。测试工程师角色`vid_g6_contract_audit`只读审查；命令、浏览器和MySQL运行由主代理完成。

独立确认stts属于轨道mdhd时基，原代码使用电影mvhd时基错误；真实FFmpeg夹具9168b9实测24fps误报1fps。修复采用唯一mdhd、0/1显式偏移、未知版本和零时基失败关闭；Fake同步补mdhd，不为兼容测试对真实输入采用缺时钟回退。

独立指出采样累计时长缺失与以codec代理轨道数量两个缺口。cbcf11三项反例实际失败；修复checked uint64累计ticks等于非零mdhd.duration，单独计数video并立即拒绝空codec。59227d原生全video通过，15609隔离复验通过。v1正例使用60亿ticks/12亿Hz，真正覆盖duration高32位。

初次130文件清单复算SOURCE为`08f1a20ebc9d17670a4480aece99a27f11875af7808ce57ed374978324ad5575`。最后仅`media_clock_test.go`收紧fractional反例：mdhd duration=61560与120×513一致，相同delta排除VFR，精确要求ErrMediaResourceLimit。89cded目标包通过；独立复算当前SOURCE为`72f699225cd56ec5c6f2c823fd7d14152871be807fcae7f2a524d74fc9f9fd30`，测试文件SHA256为`5932cd9eca4e9c8a8f7a4d0ffbf8334915187e2e8b41e1d65cebd0a219213d17`。

独立静态确认多片HTTP用例比较完整原媒体字节，第二片失败仅首1MiB及UnexpectedEOF，并等待真实服务端回收后查租约和金融整行快照。55397专项与15609回归为主代理动态证据。浏览器仅证明静态合成字节可播放，不是SK端到端；未扩展为完整MP4解码器、VFR或G7，不签全G6。
