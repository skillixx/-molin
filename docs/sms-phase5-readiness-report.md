## 4. 阻塞项

`TRUSTED_PROXY_IPS` 为空时，API 不信任 Nginx 覆盖的 `X-Real-IP`，只能使用前端容器连接地址作为来源。
这会使公网验证码入口的 IP 限流退化为“多个用户共享代理容器 IP”，可能出现误限流。

整改必须在获批测试窗口完成：

1. 冻结实际代理网络，不依赖会随容器重建漂移的单个容器 IP。
2. 为管理端、用户端创建专用且不与现有 Docker/VPC 网段冲突的固定子网。
3. 将该专用子网精确加入测试服 `TRUSTED_PROXY_IPS`。
4. 重启 API 后验证可信代理合法单值通过，缺失、多值、非法 `X-Real-IP` 均在业务前返回 403。
5. 验证轮换伪造 XFF/Forwarded 不能拆分限流桶。

禁止直接把不受控的全部 Docker 网段或 `0.0.0.0/0` 加入可信代理列表。
