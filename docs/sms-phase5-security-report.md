## 2. 当前风险

1. 测试服真实短信 Canary、五次供应商受理、OTP 未消费和五场景人工收件均已通过；5m/15m/30m/2h 观察通过，但 24h 和最终证据组装尚未完成，不能提升为完整阶段或生产验收。
2. 生产目标、网络、密钥注入、监控和回滚点尚未只读审计。
3. 前端依赖存在阶段 4 已记录的既有供应链风险，本阶段不做无关升级。
4. `verification_codes.target_value` 的历史手机号兼容列仍按阶段 4 产品决定保留；HMAC 化需独立 migration 和停发窗口。
5. 测试服 journald 已配置 `8G/50G/14day/1day` 并通过运行时验证；24 小时观察仍需确认实际日志增长未提前触发容量淘汰，不能只以静态配置推定完整观察窗口可追溯。
6. 测试服真实页面存在 1 条未能关联响应路径的静态资源 404 控制台提示；功能性控制台错误、页面异常和业务 API
   非 200 均为 0。该观察不影响短信安全门禁，但正式发布前宜由前端/运维继续定位静态资源来源。

## 3. 安全停止条件

发现完整手机号、验证码、AccessKey、JWT、Bearer Token、供应商原始响应或签名请求原文进入日志、指标、审计、
文档、截图或 Git 时，立即停止发布，关闭开关，保留脱敏调查证据并按密钥轮换流程处理。
