# 阿里云短信验证码阶段 5 安全报告

## 1. 已完成控制

- 开关默认关闭，测试模式默认开启，模板编码不进入环境变量。
- 指标仅使用五场景和八个安全结果类别，不含手机号、模板编码、业务请求号、供应商原始码、OTP 或凭据。
- 指标写入端拒绝非固定场景，并把未知错误类别收敛为 `rejected`，避免异常字符串形成常驻高基数键。
- 供应商超时、限流、签名、模板、欠费、网络和普通拒绝分别归入固定低基数类别。
- Nginx 仓库配置和测试服实际配置均覆盖 X-Real-IP、删除 XFF/Forwarded。
- 回滚 Dry Run 不连接远端、不写配置、不重启、不执行 migration、不发短信。
- 指标聚合增加并发读写测试；Linux CI 使用 `go test -race` 验证互斥保护，并独立执行 Nginx、promtool 与回滚门禁。
- 环境文件准备度检查锁定阿里云供应商和官方 Endpoint，校验独立 HMAC 最小长度，并拒绝重新引入模板编码环境变量。
- 测试服已使用独立 `/28` 固定代理网络；运行环境中的两个旧 `SMS_TEMPLATE_CODE_*` 覆盖项已移除，数据库绑定保持唯一真相源。
- 关闭态双代理请求均为 `503/50300`；发送日志、手机验证码行、Provider 指标和完整白名单号码日志均无增量。
- 部署后只读脚本通过 stdin 向 curl 和容器内 mysql 传递内部 Token/数据库密码，敏感值不进入宿主机命令参数。

## 2. 当前风险

1. 真实短信 Canary、告警触发演练和 24 小时观察尚未执行。
2. 生产目标、网络、密钥注入、监控和回滚点尚未只读审计。
3. 前端依赖存在阶段 4 已记录的既有供应链风险，本阶段不做无关升级。
4. `verification_codes.target_value` 的历史手机号兼容列仍按阶段 4 产品决定保留；HMAC 化需独立 migration 和停发窗口。
5. 测试服 journal 当前占用约 2.3G，但尚无留存天数或轮转策略的直接证据。

## 3. 安全停止条件

发现完整手机号、验证码、AccessKey、JWT、Bearer Token、供应商原始响应或签名请求原文进入日志、指标、审计、
文档、截图或 Git 时，立即停止发布，关闭开关，保留脱敏调查证据并按密钥轮换流程处理。
