## 2. 测试服务器只读基线

获得测试服务器 SSH 凭据的安全注入后，先使用单次受控只读会话收集以下低敏结果，不输出环境值、用户数据或日志正文：

| 项目 | 必须证据 | 失败处理 |
|---|---|---|
| 目标身份 | hostname、machine-id 摘要、SSH ED25519 指纹 | 与批准目标不同立即停止 |
| API 制品 | 进程数、启动时间、二进制 SHA-256、提交摘要 | 多实例或摘要无法对应时停止 |
| 配置 | 文件类型、属主、权限、变量名集合摘要 | 不读值；权限过宽或键集越权即停止 |
| MySQL | 版本、schema `66:0`、核心表行数与数据/索引大小 | dirty、版本不符或无法只读时停止 |
| Redis/RabbitMQ | 版本、存活、队列/积压聚合计数 | 不扫描业务 key，不消费队列 |
| Bifrost | 节点数、镜像 digest、LB 健康、变量名精确白名单 | 不调用真实模型，不输出上游密钥 |
| 可观测性 | Prometheus targets、22 条规则、16 面板、Alertmanager 默认 discard | 不发送真实通知 |
| 账务 | 只读对账三差额、hold、Outbox、补偿聚合 | 任一非零只登记，不自动修账 |
| 备份 | 最新备份时间、大小、SHA-256、可读性 | 不恢复到共享库；未验证不得进入部署 |

## 3. 不含 Secret 的迁移清单

1. 复制 `infra/ai-gateway-g8-migration-manifest.example.json` 到已忽略的 `infra/.g8-private/`。
2. 只填写主机别名、部署形态、目录别名、制品摘要、授权布尔值和聚合证据；禁止填写密码、SK、Token、JWT、DSN、客户身份或联系方式。
3. 每个生产阶段使用一份新文件、唯一 ChangeId 和不可复用的阶段审批回执；审批、测试凭据轮换仅保存仓库外回执的 SHA-256。审批回执原文必须明确绑定当前 stage、ChangeId、精确目标、命令摘要、请求/费用上限、影响、回滚和停止条件。校验器输出当前清单 `receipt_sha256`，下一阶段必须写入 `previous_manifest_sha256`。
4. 校验时从测试候选开始按顺序传入全部不可变清单，不能只传最终阶段：

```powershell
python infra/scripts/verify-ai-gateway-g8-migration-manifest.py `
  --manifest infra/.g8-private/01-test-candidate.json `
  --manifest infra/.g8-private/02-production-readonly.json `
  --manifest infra/.g8-private/03-production-closed-deploy.json
```

校验器精确限制四个阶段：

- `test_candidate`：只允许测试候选，双总闸关闭、生产授权全 false、请求数和费用为 0，不引用前序或审批回执。
- `production_readonly`：必须紧接测试候选并绑定其摘要及生产只读审批回执，不部署、不请求、不开流量。
- `production_closed_deploy`：必须紧接只读阶段并绑定其摘要、关闭态部署审批和测试凭据轮换回执；备份/回滚/零差额/凭据隔离证据齐全，仍不请求、不开流量。
- `production_gray`：必须紧接关闭态部署并绑定其摘要、灰度审批和凭据轮换回执；另有付费上游、客户灰度和真实通知授权，设置正数请求/费用上限，批准 5～8 个文字模型、2 个上游、价格和不低于 15% 的毛利底线。

校验器会重新校验链上每份清单、前序摘要、ChangeId 与各生产阶段审批回执唯一性、测试源身份、同一发布制品和只读确认后的生产目标一致性，并拒绝非规范生产路径。布尔值或摘要不能替代仓库外审批或轮换事实；回执原文必须由受控系统保存，不能写入 Git。

## 4. 生产迁移规则

- 生产是重建受控配置，不是复制测试服务器整份 `.env`、数据库、密钥或客户数据。
- 测试与生产必须使用独立 SSH 身份、Secret、数据库、Redis、RabbitMQ、Bifrost 上游账号、监控 Token 和告警接收人。
- 生产首次部署保持边缘 kill switch 和 `AI_GATEWAY_TRAFFIC_ENABLED=false`；不在同一变更中同时部署并开流量。
- Migration `000060`～`000066` 必须在生产只读基线后逐项评估行数、索引大小、`EXPLAIN ALTER`、锁级别、临时空间、超时和中止条件；测试库耗时不得外推到生产。
- 回滚只切换应用、路由或开关，不删除请求账本、Usage、价格快照、hold、钱包流水、Outbox、审计和申诉事实。
